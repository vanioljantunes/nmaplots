nmaplots tutorial

From an Excel sheet to a publication-ready network plot in three steps

Excel sheet→ pairwise()→ netmeta()→ nmaplot()
1

Prepare packages

install once, load every session
# install once
install.packages(c("remotes", "netmeta", "rstudioapi", "readxl"))
remotes::install_github("vanioljantunes/nmaplots")

# load every session
library(nmaplots)

library(rstudioapi)
library(readxl)

Updating nmaplots in an open session? Run unloadNamespace("nmaplots") before install_github(), then library(nmaplots) again, so the new version is the one in use.

Pick the file, then the sheet

# opens a file picker in RStudio
myfile <- selectFile()

# read every sheet into a list named ma
sheet_names <- excel_sheets(myfile)
ma <- lapply(sheet_names, function(x)
  as.data.frame(read_excel(myfile, sheet = x)))
names(ma) <- sheet_names

# choose the outcome sheet
sheet <- select.list(sheet_names, title = "Which sheet?")
d <- ma[[sheet]]      # same as ma$rec_pat_all

3

Run nmaplot()

pairwise → netmeta → nmaplot
# a. arm rows -> one row per comparison
p <- pairwise(treat = treatment, event = responders,
              n = sampleSize, studlab = study,
              data = d, sm = "RR")

# b. fit the network meta-analysis on p
net <- netmeta(p)

# c. draw it
nmaplot(net,
        outcome        = "Patient recurrence",
        layout         = "multi",
        node_fill      = "#A94A47",
        reference_fill = "#8A939B",
        ring_colors    = c(Events = "#4E7CA8",
                           "No event" = "#DFE3E7"))

# d. save for the paper
nmaplot(net, outcome = "Patient recurrence",
        file = "network.png",
        width = 10, height = 10.5, dpi = 300)
Give netmeta() the pairwise object netmeta(p), not netmeta(d). Passing the sheet itself stops with Non-numeric value for argument 'TE'.
Numbers with decimal commas? A sheet saved as "-0,684" reads as text. nma_clean(d) converts it; nmaplot() also accepts pairwise rows directly.
Outcomeoutcome = "X"
Text of the subtitle under the title. Write the outcome in words, e.g. "Patient recurrence". The line below it (studies, treatments, patients, events) is added automatically; summary_line = FALSE hides it. title changes "Network of Interventions".
Layoutlayout = "multi"
"multi" polygon (default), "circle" ordered by connections, "star" reference in the centre (reference = "Placebo").
Node coloursnode_fill, reference_fill
node_fill every treatment
reference_fill reference
highlight + highlight_color
Any R colour or hex. node_fill = "auto" gives one colour per treatment from palette. The % inside turns yellow on dark fills.
Outer ring coloursring_colors
Events / "No event"
A named vector, names = ring groups: c(Events = "#4E7CA8", "No event" = "#DFE3E7"). A custom ring (e.g. ring = table(d$treatment, d$design)) takes one colour per group; ring = FALSE removes it.
